# Laptop 2 — optional interface review

The dispatch dashboard and routing core already run together. Start the app
using the Windows dashboard commands in README.md. Use the Varanasi preset
when a local snapshot is present.

1. Try the preset, switch plans, and check that both map routes are readable.
2. Try one narrow screen. If needed, adjust spacing, legend, or colors in app.py.
3. Report the screen size and any issues you reproduced. Submit visual changes
   on your UI branch. Core algorithms, map integration, and dispatch controls
   are already implemented.
